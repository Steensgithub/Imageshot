# ImageShot – privacy policy / privatlivspolitik

_Last updated: 2026-10-16_

**English.** ImageShot (the Windows program and the browser extension) does not collect, send or sell any
personal data. Screenshots are created and processed only on your own computer. They are copied to your
clipboard or saved where you choose; the browser extension keeps a capture in the browser's local storage
(IndexedDB) only until its window is closed. There are no accounts, no analytics, no advertising and no
tracking. The only network request the Windows program makes is an optional check for a newer version
(GitHub Releases), which can be turned off in Settings; it sends no personal data. Text recognition uses the
engine built into Windows and runs offline.

Browser permissions: *activeTab* and *scripting* to capture the page you choose; *downloads* to save files;
*clipboardWrite* to copy; *storage* for your settings; *contextMenus* for the right-click menu. Access to all
sites (`<all_urls>`) is optional and only requested when you capture all tabs.

**Dansk.** ImageShot (Windows-programmet og browserudvidelsen) indsamler, sender eller sælger ingen
persondata. Skærmbilleder laves og behandles kun på din egen computer og kopieres eller gemmes, hvor du
vælger. Udvidelsen gemmer et billede lokalt i browseren (IndexedDB), kun indtil vinduet lukkes. Ingen konti,
ingen statistik, ingen reklamer. Windows-programmet søger (kan slås fra) efter nye versioner på GitHub uden at
sende persondata. Tekstgenkendelse bruger Windows' egen motor uden internet.
