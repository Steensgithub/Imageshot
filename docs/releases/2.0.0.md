## ImageShot 2.0.0

Første udgave under navnet **ImageShot** (tidligere "Skærmbillede").

**Windows-program**
- Tegneværktøjer i editoren: pil, firkant, ellipse, overstreg, tekst, trinnumre, slør og pixelering
- Kopiér tekst fra billedet (tekstgenkendelse, uden internet)
- Fastgør et billede øverst på skærmen
- Seneste billeder i menuen, optagelse med forsinkelse (3/5/10 s)
- Filnavneskabelon med {date} {time} {title} {app} {counter} og undermapper
- Lyst og mørkt udseende, nyt ikon, lup og piletaster ved markering
- Dansk, engelsk, tysk og spansk
- PrtScn virker også på Windows 11 (Skærmklip tager ikke tasten)
- Installationsprogram, automatisk søgning efter opdateringer

**Browserudvidelse**
- Tegneværktøjer og slør i udklipsholder-vinduet
- 4 sprog, færre tilladelser, billeder gemmes lokalt kun indtil vinduet lukkes

**Installation:** kør `ImageShot-Setup-2.0.0.exe` (kræver ikke administrator). Bærbar udgave: `ImageShot-2.0.0-portable.zip`.
